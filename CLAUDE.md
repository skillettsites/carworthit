# CarWorthIt project notes

US used-car valuation site (carworthit.com, apex; www 308s to apex via Vercel). Never target UK terms or link to carcostcheck.co.uk.

## Content built 15 Sep 2026 (159 sitemap URLs)
- Every fact page carries a "verified/checked <date>" line and per-row sources. Datasets: `src/content/state-fees.json` (51 states x 6 fee groups, each cell has source URL + verbatim quote + checked date; refresh quarterly, next due 15 Dec 2026; see `src/lib/state-fees.ts` header), `src/lib/vhr-providers.ts` (history-report prices, re-check on each provider's own site), `src/content/vin-tools/wmi.json` (WMIs pulled from NHTSA vPIC, never hand-typed), `src/lib/vin-tools/window-sticker.ts` (OEM sticker endpoints with verification status; children only where verified).
- Hubs: /vehicle-history-faq (first in llms.txt), /best-vehicle-history-report, /car-sales-tax-calculator (+51 state pages), /out-the-door-price-calculator, /dealer-doc-fee-by-state, /car-registration-fees-by-state, /negotiate-used-car-price, /title-check, /lien-check, /odometer-check, /stolen-vehicle-check, /vin-decoder/[make] x12, five vehicle-type decoders, /transmission-by-vin, /engine-by-vin, /vin-year-chart, /paint-code-by-vin, /window-sticker (+5 makes), /check-warranty-by-vin.
- 8 permanent redirects in next.config.ts consolidate thin duplicates; do not recreate the old slugs.
- Article bodies in `src/content/articles.json` are stored entity-escaped; the blog renderer decodes them. The 17 common-problems posts carry a NHTSA complaints table (built from api.nhtsa.gov) and `updated` dates.
- Honesty rules: not an NMVTIS provider, no history data, no affiliation claims; the free decode is vPIC and pages must not promise fields vPIC does not return.

## Value cluster built 16 Sep 2026: the listings behind the number
- Retail Market Value (US), VIN Audit via OneAuto: `getRetailMarketValue(vin, mileage)` in `src/lib/apis/oneauto.ts`, path `/vinaudit/retailmarketvalue/us/` (probed; not in Swagger yet), 24p a call, Data Cache 7 days per VIN+mileage. NATIONAL figures for the exact year/make/model/trim at that mileage: mean, sd, count, confidence, window, low/avg/high, 10 price bands, mileage adjustment, up to 1,000 listings each with ZIP/state/lat/lng, observed mileage, advertised and mileage-adjusted price. Consumer display of the listings inside a PAID report confirmed in writing by Mark Fretwell (OneAuto) 15 Sep 2026. Carketa stays the headline local number and its comparables stay trade-only.
- `src/lib/market-evidence.ts` derives the local view (radius 50/100/250/500 mi until 8 listings; ZIP centroids from `src/content/zcta.ts`, Census 2024 gazetteer, kept as a JSON string so tsc does not type 33k keys), percentile of the asking price, strength label, band chart. `src/components/report/MarketEvidence.tsx` renders it; rows shown: Valuation 5, Full Report 12, Negotiation 30 (sample 12).
- Report flow (`src/app/report/[vin]/page.tsx`): paid tiers fetch RMV alongside Carketa; the cwi_reports payload now carries `evidence` (older rows are healed on next visit). If Carketa misses but RMV has data, `valuationFromEvidence()` stands in with `basis: 'national'` and every sentence says so (verdict + negotiation copy are basis-aware). The negotiation pack takes `evidence` and adds "N of the M within R miles are cheaper" levers. `FREE_EVIDENCE_TEASER` is OFF (Dave, 16 Sep 2026: paid feeds are only called on a purchase); on, it would call RMV once per free VIN view to show the listing count and seed a model page where none exists.
- Model pages `/car-value/[year-make-model]` (+ index `/car-value`): data in Supabase `cwi_model_values` (public aggregates only, anon SELECT). Writes ONLY via `upsert_cwi_model_value(p_secret, p_row)`, a SECURITY DEFINER function checking `cwi_secrets` (no policies, anon cannot read); the secret is `CWI_WRITE_SECRET` (Vercel prod+preview and .env.local). Seed script: scratchpad `cwi2/seed_models.mjs` (`saved` | `pilot <n>` | `revalue`), synthetic VINs from NHTSA complaint prefixes (`cwi2/../nhtsa/prefixes.json`, 10,519 model-years); targets from Keyword Planner "[year] [make] [model] value" queries (`cwi2/model_targets_value.json`, 79 rows). Strike at the pool's median mileage (two-pass) or the page headline is wrong for old cars. 27 pages seeded 16 Sep (about £9).
- New pages: /how-much-is-my-car-worth (rewritten, dated Corolla example), /kbb-by-vin, /is-kbb-accurate (measured spreads table), /car-value, /car-value/[slug]. Homepage title now leads on "How much is a car worth". Sample report carries a real evidence snapshot (`src/content/sample-evidence.json`, 60 nearest listings to ZIP 10312, VINs dropped).
- Keyword facts (Google Keyword Planner US, Sep 2026): "how much is my car worth" 40,500/mo, "what is my car worth" 22,200, "my car value" 33,100, "car value by vin" cluster 14,800, "kbb by vin / kelley blue book vin lookup" cluster 14,800, "is kbb accurate" ~1,500, KBB-branded 3.35M. - Free report (16 Sep, later the same day): works like CarCostCheck, free report then upsell. `src/components/report/FreeExtras.tsx` renders ONLY free data: our own model-value rows (getModelValues by year-make-model slug, or other years of the model), NHTSA complaints (`src/lib/nhtsaComplaints.ts`, free API, 30-day cache, top 5 components), a mileage-for-age yardstick (FHWA 13,500/yr), and the visitor's state tax/fees from the state dataset via the `x-vercel-ip-country-region` header.
